# 🎮 虚拟键盘高度变化快速参考指南

## 📌 一句话总结
**监听虚拟键盘的高度变化，根据键盘是否打开来动态调整输入框位置，防止被键盘遮挡。**

---

## ⚡ 5分钟快速上手

### 核心代码（复制即用）

```java
@Override
public void onKeyboardHeightChanged(int height, int leftInset, int rightInset, int orientation) {
    
    // 键盘关闭（height=0）
    if (height == 0) {
        inputContainer.animate().y(0).setDuration(100).start();
        return;
    }
    
    // 键盘打开（height>0）
    inputContainer.setX(0);
    inputContainer.setScaleX(1);
    inputContainer.setY(0);
    
    float scaleX = (float)(screenWidth - leftInset - rightInset) / screenWidth;
    float offsetX = (float)(leftInset - rightInset) / 2;
    
    inputContainer.animate()
            .y(-height)
            .scaleX(scaleX)
            .x(offsetX)
            .setDuration(100)
            .start();
}
```

## 📊 参数值对照表

| 参数 | 值范围 | 含义 | 例子 |
|-----|--------|------|------|
| height | 0 | 键盘关闭 | 键盘隐藏 |
| | 200-600 | 键盘打开 | 打开了400px的键盘 |
| leftInset | 0 | 无左缺口 | 普通屏幕 |
| | 50-100 | 有左缺口 | 左侧刘海屏 |
| rightInset | 0 | 无右缺口 | 普通屏幕 |
| | 50-100 | 有右缺口 | 右侧刘海屏 |
| orientation | 0 | 竖屏 | 竖着握手机 |
| | 1 | 横屏 | 横着握手机 |

## 🔄 动画参数详解

```java
container.animate()
    .y(-400)              // ⬆️ 向上移动400像素（-号表示向上）
    .scaleX(0.9f)         // 📏 缩放到宽度90%（适配左右缺口）
    .x(25)                // ↔️ 水平位置移到25px处（居中显示）
    .setDuration(100)     // ⏱️ 花100毫秒进行动画
    .start();             // ▶️ 开始执行
```

## ✅ 检查清单

实现这个功能时，确保做到：

```
□ 检查height == 0 来判断键盘是否关闭
□ 当height > 0时执行上移动画
□ 在动画前重置setX、setScaleX、setY
□ 考虑leftInset和rightInset（刘海屏）
□ 使用100ms的动画时长（通常推荐值）
□ 在onAnimationEnd中刷新自动补全菜单
□ 如果使用Immersive模式，加上软按钮栏高度
□ 测试不同屏幕尺寸和宽高比
□ 测试竖屏到横屏的旋转
□ 处理浮动键盘的特殊情况
```

## 🚨 常见错误

| 错误 | 原因 | 解决方案 |
|-----|------|--------|
| 动画后Y值错误 | 没有重置初始Y | 加`setY(0)` |
| 旋转后位置混乱 | 没有重置X和缩放 | 加`setX(0);setScaleX(1)` |
| 菜单被键盘遮挡 | 没有更新菜单位置 | 在`onAnimationEnd`中`showDropDown()` |
| 刘海屏不适配 | 忽视了insets | 使用`scaleX = (w-l-r)/w` |
| 高度值不对 | Immersive模式 | 加上软按钮栏高度 |
